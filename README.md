# Ryedale Aquarist Society Open Event

The website for the Ryedale Aquarist Society Open Event: https://event.ryedaleaquaristsociety.org.uk

It is built with Jekyll on the shared
[Ryedale Aquarist Society theme](https://github.com/RyedaleAquaristSociety/ryedale-aquarist-society-theme),
pinned in `_config.yml` by `remote_theme`. The colours are the theme's `event` skin.

Run it locally:

```
bundle install
bundle exec jekyll serve
```
